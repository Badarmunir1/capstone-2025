AI Models Used Inside app.py
M1
MobileNetV2
Style Classifier — a lightweight deep learning model. Loads weights from best_style_model.pth. Classifies the room into 1 of 4 styles.
Classic Minimalist Modern Rustic
Input: 224×224 RGB image → Output: style + % confidence
→
M2
YOLOv8 Nano
Object Detector — ultra-fast real-time detector from Ultralytics. Auto-downloads yolov8n.pt on first run. Finds furniture and household items.
chair couch bed dining table tv +16 more
Input: original PIL image → Output: list of detected objects
→
M3
KMeans Clustering
Color Palette Extractor — sklearn algorithm. Groups all pixels into 5 clusters. Finds dominant colors in the room photo.
Input: all image pixels → Output: 5 hex color codes
Full Pipeline — Step by Step (What Happens When User Clicks Analyze)
1
User uploads room photo
Gradio image widget accepts PNG/JPG upload. Or user clicks "Try an Example" which loads example.jpg from disk. Image stored as PIL (Python Image Library) object.
↓
2
process_image(image) function is called
This is the MAIN controller function in app.py. It calls all 3 AI models, collects results, and builds the final HTML output. If no image → shows error message.
↓
Three tasks run in sequence inside process_image()
🎨 predict_style()
Resizes image to 224×224. Normalizes pixels. Feeds into MobileNetV2. Gets softmax probabilities. Returns predicted style + confidence %.
↓
Output: "Rustic" at 87.4%
+
🔍 YOLOv8 detector()
Runs YOLOv8n on the image. Gets all bounding boxes with class labels. Filters only furniture from the FURNITURE_CLASSES list. Removes duplicates.
↓
Output: ["couch", "tv", "potted plant"]
+
🖌️ extract_palette()
Converts image to numpy array. Reshapes all pixels to a flat list. Runs KMeans(k=5) clustering. Converts cluster centers to hex codes.
↓
Output: ["#8B5E3C", "#E8D5A3", ...]
↓
5
generate_personalized_advice(detected_objects, style)
Smart rule-based advisor. Checks which furniture was detected → adds specific tips. Example: couch detected → "Add a textured throw and accent pillows for the rustic look." No furniture detected → fallback generic tip.
🛋️ Seating tip 📺 TV tip 🌿 Plant tip 💻 Workspace tip
↓
6
recommendations[style] — Style Lookup Dictionary
Hard-coded dictionary in app.py. Looks up the detected style (e.g. "Rustic") and retrieves furniture suggestions, layout advice, and lighting tips. No AI needed — it's a simple Python dict!
🛋️ Furniture advice 📐 Layout advice 💡 Lighting tips
↓
7
Build final html_output string
Combines ALL results into a single styled HTML string. Creates color swatches with hex codes. Creates furniture "badge" pills. Puts everything in a white card with box-shadow. Returns to Gradio to display.

Libraries from requirements.txt — What Each One Does
torch
PyTorch — the deep learning engine. Runs MobileNetV2 on GPU or CPU.
torchvision
Adds MobileNetV2 model + image transform helpers (Resize, Normalize).
ultralytics
Contains YOLOv8. Used to detect objects in the room photo.
scikit-learn
KMeans algorithm for color palette extraction from pixel data.
Pillow
PIL image library. Opens, resizes, and converts images to RGB or numpy.
numpy
Converts images to number arrays so KMeans can process pixels.
gradio
The entire web interface! Buttons, image upload, HTML display — all Gradio.
opencv-python
Image processing utility (imported by dependencies, supports image ops).
requests
HTTP library. Used internally by Gradio/HuggingFace infrastructure.
