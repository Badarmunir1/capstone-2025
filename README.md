## 📋 Overview

Interior Design Advisor (IDA) is an intelligent system that takes a photo of any room and instantly gives **personalized interior design recommendations** — color palettes, style suggestions, furniture ideas, and more.

## ✨ Key Features (Current + Planned)

- ✅ Room image upload & analysis
- ✅ Automatic color palette extraction (K-Means)
- ✅ Pre-trained feature extraction (MobileNetV2)
- 🔄 Style classification (Modern, Minimalist, Industrial, etc.)
- 🔄 Furniture & decor recommendations
- 🔄 E-commerce product linking (planned)

## 🛠 Tech Stack

- **Language**: Python 3
- **Computer Vision**: OpenCV, MobileNetV2
- **ML**: scikit-learn, TensorFlow/Keras
- **Notebooks**: Jupyter
- **Future UI**: Streamlit
